\## Захист лаби (Reflection)



\* \*\*Чим `yield` відрізняється від `return`?\*\*  

&#x20; `return` повертає результат і завершує функцію. `yield` призупиняє її, повертає значення і зберігає стан для наступного виклику `next()`.

\* \*\*Що таке Iterable та Iterator?\*\*  

&#x20; `Iterable` реалізує `\_\_iter\_\_()` і повертає ітератор. `Iterator` реалізує `\_\_next\_\_()` для послідовного отримання елементів.
