\## Куди пішла пам'ять? (Memory Breakdown)



1\. \*\*Lazy (Генератори):\*\*

&#x20;  - Використовує `yield` для потокового зчитування файлів по одному.

&#x20;  - Пам'ять не витрачається на збереження повного тексту всіх документів чи списку з 700 тисяч слів.

&#x20;  - Основний обсяг (22.56 МБ) займає структура `Counter` для підрахунку частоти унікальних слів та середовище виконання Python.



2\. \*\*Eager (Жадібна версія):\*\*

&#x20;  - Створює масив `all\_documents` з усіма текстами та список `all\_tokens` із 704 551 елементом.

&#x20;  - Пам'ять зростає більш ніж удвічі (50.33 МБ) через overhead списків Python та збереження всіх стрічок одночасно.
